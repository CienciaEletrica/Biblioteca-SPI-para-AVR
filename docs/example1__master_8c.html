Descrição detalhada

Exemplo SPI Master: Controle de fluxo e telemetria via UART.

Autor
Tiago Henrique dos Santos - Ciência Elétrica

Objetivos do Teste:

  1. Validar o Baud Rate de 125 kHz (Fosc/128).
  2. Demonstrar o envio assíncrono (non-blocking) de comandos via interrupção.
  3. Validar a recepção Full-Duplex (receber resposta do Slave enquanto envia).

Resultado Esperado:

  • O terminal serial deve exibir "Enviando: XX | Recebido: YY".
  • O primeiro byte recebido será tipicamente 0x00 (inicialização).
  • Os bytes subsequentes refletirão a resposta processada pelo Slave no ciclo anterior.

Observação
Configuração SPI Master:
  • Modo Assíncrono habilitado (use_interrupt = true).
  • Clock de 125 kHz (ideal para longas distâncias ou periféricos lentos).

Definição na linha 38 do arquivo example1_master.c.

38 {
39 uart_init();
40 uart_puts("--- SPI MASTER: 125kHz Mode ---\r\n");
41
42 /**
43 * @note Configuração SPI Master:
44 * - Modo Assíncrono habilitado (use_interrupt = true).
45 * - Clock de 125 kHz (ideal para longas distâncias ou periféricos lentos).
46 */
47 spi_config_t master_cfg = {
48 .mode = SPI_MODE_MASTER,
49 .clock_div = SPI_CLOCK_DIV_128, // 125 kHz @ 16MHz
50 .cpol = 0, // Mode 0
51 .cpha = 0,
52 .bit_order = SPI_ORDER_MSB_FIRST,
53 .use_interrupt = true, // Motor assíncrono habilitado
54 .rx_callback = 0, // Leitura manual via buffer RX
55 .pins = {
56 .port = &PORTB,
57 .mosi_pin = PB3,
58 .miso_pin = PB4,
59 .sck_pin = PB5,
60 .ss_pin = PB2
61 }
62 };
63
64 /* Inicializa o driver */
65 if (!spi_init(&master_cfg)) {
66 uart_puts("Erro na inicializacao SPI\r\n");
67 while(1);
68 }
69
70 /* Registra o escravo 0 no pino SS (PB2) */
71 spi_register_slave(0, &PORTB, PB2);
72
73 /* Habilita interrupções globais */
74 sei();
75
76 uint8_t tx_data = 0xA5;
77 uint8_t rx_data = 0;
78
79 while (1) {
80 uart_puts("Enviando: "); uart_puthex8(tx_data);
81
82 /* Seleciona o dispositivo escravo (CS em nível baixo) */
83 spi_select_device(0); // Seleciona o device
84
85 /* Envio assíncrono: O byte vai para o buffer e a ISR gerencia a transmissão */
86 spi_write_async(tx_data);
87
88 /* Aguarda a conclusão da transmissão antes de ler o buffer RX */
89 while (spi_is_busy());
90
91 /* Verifica se houve resposta do Slave no buffer de recepção */
92 if (spi_rx_read(&rx_data)) {
93 uart_puts(" | Recebido do Slave: ");
94 uart_puthex8(rx_data);
95 uart_puts("\r\n");
96 }
97
98 tx_data++;
99 _delay_ms(500); // Delay para facilitar a leitura no monitor serial
100 }
101}
