Descrição detalhada

Exemplo: Interface com Conversor D/A MCP4921 (12 bits) via SPI.

Autor
Tiago Henrique dos Santos - Ciência Elétrica

Objetivos do Teste:

  1. Validar a transmissão multi-byte (16 bits) com controle manual de Chip Select.
  2. Demonstrar a injeção de hardware (pins struct) para periféricos externos.
  3. Gerar uma rampa de tensão analógica (0V a Vref) de forma assíncrona.

Conexões Sugeridas:

  • AVR MOSI (PB3) -> MCP4921 SDI
  • AVR SCK (PB5) -> MCP4921 SCK
  • AVR SS (PB2) -> MCP4921 CS
  • LDAC (MCP4921) -> Conectar ao GND (para atualização imediata da saída)

Resultado Esperado:

  • Observar uma rampa de tensão subindo degrau a degrau a cada 500ms no pino Vout do DAC.
  • O sinal de CS (PB2) deve permanecer em nível baixo durante o envio de ambos os bytes.

Observação
Configuração SPI Master:
  • Clock de 125 kHz para garantir integridade em protoboards.
  • Modo SPI 0,0 (Polaridade 0, Fase 0) conforme datasheet do MCP4921.

Formatação do Frame de 16 bits do MCP4921:

  • bit 15: 0 (Escrever no registrador)
  • bit 14: 1 (Vref Bufferizado)
  • bit 13: 1 (Ganho 1x)
  • bit 12: 1 (Saída Ativa)
  • bits 11-0: Dados (12 bits)

Envio Multi-byte.

Parâmetros
keep_cs_lowDefinido como true para evitar que o CS suba entre os bytes.

38 {
39 /**
40 * @note Configuração SPI Master:
41 * - Clock de 125 kHz para garantir integridade em protoboards.
42 * - Modo SPI 0,0 (Polaridade 0, Fase 0) conforme datasheet do MCP4921.
43 */
44 spi_config_t dac_cfg = {
45 .mode = SPI_MODE_MASTER,
46 .clock_div = SPI_CLOCK_DIV_128, // 125 kHz (Seguro para prototipagem)
47 .cpol = 0, // MCP4921 utiliza Modo 0,0
48 .cpha = 0,
49 .bit_order = SPI_ORDER_MSB_FIRST,
50 .use_interrupt = true, // Uso de buffers TX/RX
51 .rx_callback = NULL,
52 .pins = {
53 .port = &PORTB,
54 .mosi_pin = PB3,
55 .miso_pin = PB4,
56 .sck_pin = PB5,
57 .ss_pin = PB2
58 }
59 };
60
61 /* Inicializa o driver SPI */
62 if (!spi_init(&dac_cfg)) {
63 while(1);
64 }
65
66 /* Registra o DAC como escravo ID 0 no pino PB2 */
67 spi_register_slave(0, &PORTB, PB2);
68
69 /* Habilita interrupções para o motor assíncrono */
70 sei();
71
72 while (1) {
73 /**
74 * @brief Formatação do Frame de 16 bits do MCP4921:
75 * - bit 15: 0 (Escrever no registrador)
76 * - bit 14: 1 (Vref Bufferizado)
77 * - bit 13: 1 (Ganho 1x)
78 * - bit 12: 1 (Saída Ativa)
79 * - bits 11-0: Dados (12 bits)
80 */
81 uint16_t command = 0x3000 | (dac_value & 0x0FFF);
82
83 uint8_t buffer[2];
84 buffer[0] = (uint8_t)(command >> 8); /* Byte mais significativo (MSB) */
85 buffer[1] = (uint8_t)(command & 0xFF); //* Byte menos significativo (LSB) */
86
87 /* --- Início da Transação --- */
88 spi_select_device(0); /* Abaixa o pino CS */
89
90 /**
91 * @brief Envio Multi-byte.
92 * @param keep_cs_low Definido como true para evitar que o CS suba entre os bytes.
93 */
94 spi_write_multi(buffer, 2, true);
95
96 /* Aguarda o driver terminar o envio físico dos buffers */
97 while (spi_is_busy());
98
99 spi_deselect_device(); /* Levanta o pino CS para o DAC processar o dado */
100 /* --- Fim da Transação --- */
101
102 /* Incrementa a rampa (degraus de 64). Retorna a 0 ao atingir 4096. */
103 dac_value = (dac_value + 64) & 0x0FFF;
104
105 _delay_ms(500);
106 }
107}
