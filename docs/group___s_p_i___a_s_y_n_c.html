◆ spi_write_async()

bool spi_write_async ( uint8_t data)

Enfileira um byte para transmissão assíncrona.

Parâmetros
[in]dataByte a ser transmitido.
Retorna
true se o byte foi enfileirado no buffer TX.
false se o buffer TX estiver cheio.
Exemplos
example1_master.c e example3.c.

Definição na linha 183 do arquivo spi.c.

183 {
184 if (!spi.config.use_interrupt) return false;
185
186 // Bloco atômico para evitar corrupção dos índices do buffer
187 ATOMIC_BLOCK(ATOMIC_RESTORESTATE) {
188 uint8_t head = spi.tx_head;
189 uint8_t tail = spi.tx_tail;
190 uint8_t used = (head >= tail) ? (head - tail) : (SPI_TX_BUFFER_SIZE - tail + head);
191
192 if (used >= (SPI_TX_BUFFER_SIZE - 1)) {
193 spi.tx_overflow = true;
194 return false;
195 }
196 spi.tx_buffer[spi.tx_head] = data;
197 spi.tx_head = spi_buf_next(spi.tx_head, SPI_TX_BUFFER_SIZE);
198 }
199
200 // Se o driver estiver parado, inicia a transmissão imediatamente
201 if (spi_state == SPI_STATE_IDLE) {
202 if (spi.current_slave_id < SPI_MAX_SLAVES) {
203 spi_hw_select_slave(spi.current_slave_id);
204 }
205 spi_hw_start_tx_pipeline();
206 }
207 return true;
208}

◆ spi_write_multi()

bool spi_write_multi ( const uint8_t * buf,
uint8_t len,
bool keep_cs_low )

Inicia uma transação multi-byte assíncrona.

Parâmetros
[in]bufPonteiro para o array de dados.
[in]lenTamanho dos dados em bytes.
[in]keep_cs_lowSe true, mantém o pino CS baixo após o término.
Retorna
true se todos os bytes foram enfileirados com sucesso.
false se não houver espaço suficiente no buffer ou módulo ocupado.
Exemplos
example2.c.

Definição na linha 210 do arquivo spi.c.

210 {
211 if (!spi.config.use_interrupt || spi.busy || len == 0) return false;
212
213 // Salva estado de CS antes de enfileirar
214 spi.multi_cs_active = keep_cs_low;
215
216 for (uint8_t i = 0; i < len; i++) {
217 if (!spi_write_async(buf[i])) {
218 // Se falhar no meio, opcionalmente limpamos tudo
219 spi_tx_flush();
220 return false;
221 }
222 }
223 return true;
224}
