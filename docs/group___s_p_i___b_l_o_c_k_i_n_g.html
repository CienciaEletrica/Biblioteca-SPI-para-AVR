uint8_t spi_transfer_blocking ( uint8_t data)

Transfere um byte de forma síncrona via polling.

Parâmetros
[in]dataByte a ser enviado.
Retorna
uint8_t Byte recebido durante a troca ou 0xFF em caso de timeout.
Observação
Utiliza um contador simples para timeout definido em spi_config_t.

Definição na linha 172 do arquivo spi.c.
