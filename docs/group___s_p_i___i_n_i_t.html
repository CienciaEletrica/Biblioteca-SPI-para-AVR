bool spi_init ( const spi_config_t * cfg)

Inicializa o módulo SPI.

Configura o hardware SPI de acordo com a estrutura fornecida. No ATmega328P, configura automaticamente PB5 (SCK), PB3 (MOSI), PB4 (MISO) e PB2 (SS).

Parâmetros
[in]cfgPonteiro para a estrutura spi_config_t com os parâmetros desejados.
Retorna
true se a inicialização foi bem-sucedida.
false se houver parâmetros inválidos ou erro de hardware.
Observação
Habilita pull-up no pino SS para evitar entrada acidental em modo slave.
Exemplos
example1_master.c, example1_slave.c, example2.c e example3.c.

◆ spi_set_clock()

void spi_set_clock ( spi_clock_div_t new_div)

Altera dinamicamente o divisor de clock do SPI.

Parâmetros
[in]new_divNovo divisor de clock (baseado em spi_clock_div_t).
Observação
Esta função aguarda qualquer transmissão em andamento terminar antes de aplicar.

Altera dinamicamente o divisor de clock do SPI.

Esta função garante que a mudança de velocidade não ocorra durante uma transmissão ativa, o que causaria corrupção de dados ou comportamento errático no escravo.

Parâmetros
[in]new_divNovo divisor de clock baseado em spi_clock_div_t.
