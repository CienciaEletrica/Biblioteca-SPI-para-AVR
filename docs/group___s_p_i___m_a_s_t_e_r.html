◆ spi_register_slave()

void spi_register_slave ( uint8_t id,
volatile uint8_t * port,
uint8_t pin )

Registra um pino de Chip Select (CS) para um dispositivo escravo.

Parâmetros
[in]idIdentificador do escravo (0 até SPI_MAX_SLAVES - 1).
[in]portPonteiro para o registrador PORT (ex: &PORTB).
[in]pinNúmero do pino no porto (0 a 7).
Observação
O pino deve ser configurado como saída manualmente pelo usuário.
Exemplos
example1_master.c, example2.c e example3.c.

Definição na linha 156 do arquivo spi.c.

156 {
157 if (id >= SPI_MAX_SLAVES) return;
158 spi.slaves[id].port = port;
159 spi.slaves[id].pin_mask = (1u << pin);
160 *port |= (1u << pin); // CS inicia em HIGH
161 *(port - 1) |= (1u << pin); // Configura DDR como saída
162}
