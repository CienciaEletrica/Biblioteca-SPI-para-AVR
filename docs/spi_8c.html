Descrição detalhada

Implementação completa do driver SPI para microcontroladores AVR.

Este arquivo contém a lógica de manipulação de registros, gerenciamento de buffers circulares e a máquina de estados para operações assíncronas.

ISR ( SPI_STC_vect )

Interrupt Service Routine para o término de transferência SPI.

Este é o motor da biblioteca no modo assíncrono. A cada byte concluído, a ISR:

  1. Lê o byte recebido e o enfileira no buffer RX.
  2. Executa o callback do usuário (se registrado).
  3. Verifica se há mais bytes no buffer TX para enviar.
  4. Gerencia o pino de Chip Select (CS) caso a transação termine.
  5. Monitora e recupera colisões de escrita (WCOL).
