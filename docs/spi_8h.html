Descrição detalhada

Interface pública (API) da biblioteca SPI para microcontroladores AVR.

Autor
Seu Nome / Equipe
Versão
1.0
Data
2024

Esta biblioteca fornece uma camada de abstração (HAL) para o periférico SPI dos AVRs (foco ATmega328P). Suporta modos Master/Slave, operação síncrona (polling) e assíncrona (interrupção com buffers circulares).

Observação
Esta é a camada de abstração que o usuário deve utilizar. Não inclua spi_internal.h nem acesse diretamente registradores do SPI.
Aviso
Não chame funções SPI dentro de ISRs de outros periféricos sem cuidado (risco de deadlock ou corrupção de estado).
