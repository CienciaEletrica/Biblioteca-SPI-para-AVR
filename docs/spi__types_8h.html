Descrição detalhada

Definições de tipos, enums e estruturas para a biblioteca SPI.

Projetada para microcontroladores AVR (ATmega48/88/168/328). Foca em baixo consumo de recursos e segurança em ambientes com interrupção.

Observação
Tamanhos de buffer devem ser potências de 2 para otimização de performance.
